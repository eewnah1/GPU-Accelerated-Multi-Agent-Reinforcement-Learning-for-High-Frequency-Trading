What it is

A JAX-based framework for multi-agent reinforcement learning on high-frequency trading data. It combines a GPU-accelerated limit-order-book simulator, the JaxMARL multi-agent stack, and IPPO training with massive environment parallelism.

JAX vmap LOBSTER data GPU/CPU

Agent types

  • Market makers – post bid/ask quotes, manage inventory, earn PnL.
  • Execution agents – trade large orders with minimal market impact.
  • Directional traders – take simple long/short positions at best prices.

Repository layout

  • config/env_configs/ – environment JSON configs
  • config/rl_configs/ – training YAML configs
  • gymnax_exchange/jaxen/ – environments (marl, mm, exec)
  • gymnax_exchange/jaxrl/MARL/ – IPPO + baselines
  • gymnax_exchange/jaxlobster/ – LOBSTER data loader

Quick start

conda create -n jaxmarl_hft python=3.10
pip install "jax[cuda12]"
pip install -r requirements.txt
export PYTHONPATH="$(pwd):$PYTHONPATH"
python3 gymnax_exchange/jaxrl/MARL/ippo_rnn_JAXMARL.py \
  --config-name="ippo_rnn_JAXMARL_2player" \
  WANDB_MODE="disabled"
